RÈGLES QUI COMPTENT POUR LE RÉFÉRENCEMENT
- Les mots-clés importants dès la première ligne (c'est la seule visible sans « plus »).
- 5 à 7 hashtags : 1 de marque (#jtdeschatons) + 2 à 3 du sujet + 2 de niche (chat, IA) + 1 large (actu).
  Trop de hashtags dilue le message pour l'algorithme.
- Le même mot-clé dans la description, dans le texte à l'écran et dans la voix renforce le référencement.
  C'est déjà le cas dans les vidéos (accroche + sous-titres).
- Garde toujours #jtdeschatons : c'est ta marque, elle regroupe toutes tes vidéos dans la recherche.
